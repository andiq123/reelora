## Made for the couch

Reelora turns movie discovery into a fast, focused TV experience. Browse what is trending, playing in cinemas, popular across movies and television, or explore animation—without layouts designed for a phone stretched onto a large screen.

## Highlights

- Smooth directional navigation with clear focus states built for a TV remote
- Cinematic rotating artwork and responsive motion that stays lightweight
- Dedicated discovery pages for trending, cinemas, movies, series, and animation
- Fast search with suggestions, the native TV keyboard, and voice input
- Rich title details with artwork, synopsis, ratings, genres, cast, trailers, and availability
- Select any cast member to instantly explore their movies and television work
- Compact upcoming-release dates, provider badges, and relevant recommendations
- Optimized layouts for Android 11 televisions and Fire TV devices

## A clean discovery flow

Move from a featured title to its cast, related work, trailer, or streaming availability without leaving the remote-first interface. Every carousel keeps the active card fully visible and every detail view preserves a predictable path back.

## Install

Download **ReeloraTV-latest.apk** from the link above, allow installation from unknown sources on the TV, and open the APK. The package is updated automatically whenever a change lands on `main`.

Reelora is a personal discovery app, not a streaming service. Provider availability is informational and trailers open through an installed YouTube-compatible TV app.

## Data notice

This product uses the TMDB API but is not endorsed or certified by TMDB. Streaming availability data is supplied through TMDB's JustWatch integration.
